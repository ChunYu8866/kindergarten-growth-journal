# 幼兒園照片成長日誌

給幼兒園老師使用的 1:1 純照片成長日誌編輯器。每張成品最多 4 張照片，套用 24 款版型後可調整每張照片的位置與大小，最後下載 2480 × 2480 JPG。

## 已完成功能

- 每張成品最多 4 張照片，多選時會明確提示上限
- 24 款 1:1 版型，其中 23 款有花草、森林動物、四季、海洋、彩虹、恐龍、農場、太空或玩具水彩裝飾
- 「純淨四拼」是唯一無裝飾版型，讓 4 張方形照片以 2 × 2 無縫滿版拼在一起
- 所有相框只有 1:1 或橫式 4:3，沒有直式相框；照片以 cover 滿版填滿框內，版面不再只有中央小圖
- 照片調整比照 Canva：拖曳與指標 1:1 同步，滾輪／雙指縮放會固定住指標下的那一點
- 選取後四個角都有把手可縮放，拖曳時框外被裁掉的部分會變淡顯示，看得到自己切掉什麼
- 縮放範圍 100%–500%，方向鍵微調（Shift 加大步距），+／− 縮放
- 一般版型使用乾淨細框，「拍立得手帳」保留較寬下框；「純淨四拼」不加邊框與陰影
- 有裝飾版型的圖層順序為底色／紋理 → 大幅照片相框 → 水彩裝飾；「純淨四拼」只有底色 → 照片
- 裝飾版型的中央維持大面積透明，主體照片仍清楚，邊角則保留小花、小草、小動物與季節元素
- 照片可拖曳排序，也有前移／後移按鈕；每一列右側都有刪除鍵，可直接移除已加入的照片
- 匯出成品只有照片及所選版型的裝飾，不加姓名、日期或說明文字；「純淨四拼」不會加入裝飾
- 匯出 2480 × 2480 JPG；使用裝飾版型時會先等裝飾框載入完成
- 這個尺寸是 A4 可列印寬度（21 cm）的 300 DPI，可直接送印，不只是螢幕觀看
- 檔案大小上限 2.5 MB：先降畫質再降尺寸；一般照片實測 1.46 MB，一律用最高畫質
- 畫布以 high 品質重新取樣，避免把大張手機照片縮進小格子時糊掉
- 手機與平板改走系統分享面板，選「儲存影像」即可直接存進相簿；桌機維持一般下載
- 響應式桌機／手機介面與鍵盤操作
- 所有照片只在瀏覽器本機處理，不會上傳到伺服器
- 裝飾框改用 WebP 並按需載入；無裝飾版型不會下載任何裝飾框

## 本機開發

```bash
pnpm install
pnpm dev
```

開啟終端顯示的本機網址即可使用。其他指令：

| 指令 | 用途 |
| --- | --- |
| `pnpm build` | 產生靜態網站到 `out/`，與 GitHub Actions 上跑的是同一條路徑 |
| `pnpm preview` | 在本機以靜態伺服器預覽 `out/` |
| `pnpm lint` | ESLint |
| `pnpm typecheck` | TypeScript 檢查 |

需要 Node.js 22.13 以上。
