# 幼兒園照片成長日誌

給幼兒園老師使用的 1:1 純照片成長日誌編輯器。每張成品最多 4 張照片，套用 17 款版型後可調整每張照片的位置與大小，最後下載 2048 × 2048 PNG。

## 已完成功能

- 每張成品最多 4 張照片，多選時會明確提示上限
- 17 款 1:1 版型：1 款「純組圖」完全無裝飾，其餘 16 款各有花草、森林小動物或四季水彩邊角裝飾
- 照片層滿版鋪滿整個 1:1 畫布，四邊不留背景留白，格子之間只有一道細縫
- 照片調整比照 Canva：拖曳與指標 1:1 同步，滾輪／雙指縮放會固定住指標下的那一點
- 選取後四個角都有把手可縮放，拖曳時框外被裁掉的部分會變淡顯示，看得到自己切掉什麼
- 縮放範圍 100%–500%，方向鍵微調（Shift 加大步距），+／− 縮放
- 照片以 cover 方式填滿格子，四張的版型每格約佔畫布一半
- 照片之間只有一道背景色細縫，不加白框與陰影（「拍立得手帳」例外，白框是那款的特色）
- 圖層順序為底圖 → 照片 → 裝飾框，花草、小動物與四季裝飾疊在照片上方壓住邊緣
- 裝飾圖以放大裁切的方式往四邊外推，只壓住照片外緣約 10–18%，中間留給照片
- 照片可拖曳排序，也有前移／後移按鈕可使用
- 匯出成品只有照片與裝飾，不加姓名、日期或說明文字
- 匯出 2048 × 2048 PNG，匯出前會等裝飾框載入完成，不會漏掉裝飾
- 手機與平板改走系統分享面板，選「儲存影像」即可直接存進相簿；桌機維持一般下載
- 響應式桌機／手機介面與鍵盤操作
- 所有照片只在瀏覽器本機處理，不會上傳到伺服器
- 裝飾框改用 WebP 並改成按需載入，開站只抓目前版型用到的那一張

## 本機開發

```bash
pnpm install
pnpm dev
```

開啟終端顯示的本機網址即可使用。其他指令：

| 指令 | 用途 |
| --- | --- |
| `pnpm build` | 產生靜態網站到 `out/`，與 GitHub Actions 上跑的是同一條路徑 |
| `pnpm preview` | 在本機以靜態伺服器預覽 `out/` |
| `pnpm lint` | ESLint |
| `pnpm typecheck` | TypeScript 檢查 |

需要 Node.js 22.13 以上。
